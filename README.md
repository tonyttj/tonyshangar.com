# Tony’s Hangar — tonyshangar.com

Engineering portfolio of Tony Jürgens, mechanical engineering student at TU Eindhoven
(electric aviation, experimental aerodynamics).

Hand-built static site: plain HTML, CSS and a little vanilla JavaScript — no build step,
no frameworks, no web fonts. Hosted on GitHub Pages.

- `index.html` — the page
- `styles.css` — all styling (hangar theme)
- `script.js` — scroll progress, active-section nav, scroll story, departures board
- `assets/` — photos and figures (metadata stripped)
- `404.html` — "bay empty" page

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
